# Missão Suporte de Vida

## Descrição

Este projeto monitora os sistemas essenciais de suporte de vida de um módulo
espacial, verificando os níveis de oxigênio, a pressão do módulo e o sistema de
reciclagem de água.

## Camadas do ambiente

- **develop**: ambiente de desenvolvimento, usado para implementar e integrar
	novas funcionalidades e correções.
- **stage**: ambiente de homologação, usado para validar a versão integrada em
	condições próximas às de produção.
- **main**: ambiente de produção, que contém a versão estável e liberada do
	sistema.
